# README - C Programs Collection

## Overview
This repository contains multiple C programs that perform various tasks such as prime number detection, finding the second largest number in an array, summing two arrays, computing power and cube values, calculating averages, and determining the minimum and maximum values in an array.

## Programs Description

### 1. **Prime Number Finder**
   - This program prints all prime numbers between 2 and 100.
   - Uses a function to check if a number is prime.

### 2. **Finding Second Largest Number in an Array**
   - Accepts user input for an array and determines the second largest element.
   - Uses a function to find and return the second largest value.

### 3. **Sum of Two Arrays**
   - Accepts two arrays from the user.
   - Sums corresponding elements and stores them in a new array.

### 4. **Power Calculation**
   - Computes the power of a given base and exponent using a loop.

### 5. **Cube Calculation Until Zero**
   - Continuously reads float numbers from the user.
   - Computes and prints the cube of each number until the user inputs zero.
   - Outputs the sum of all cube values.

### 6. **Average Age Calculation**
   - Takes five age values from the user and calculates their average.

### 7. **Finding Minimum and Maximum in an Array**
   - Accepts an array from the user and determines the minimum and maximum values.
   - Uses a function that updates the min and max values using pointers.

### 8. **Pointer and Character Array Implementation**
   - Demonstrates pointer usage and a simple character array implementation.

## How to Run
1. Compile the program using a C compiler, e.g., GCC:
   ```sh
   gcc filename.c -o output
   ```
2. Run the compiled executable:
   ```sh
   ./output
   ```
3. Follow the on-screen prompts to enter inputs as required.

## Requirements
- A C compiler (GCC, Clang, or MSVC)
- Basic understanding of C programming
